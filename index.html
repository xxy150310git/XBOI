管理后台

管理员登记成员、发放或扣除 X 币、录入比赛成绩。

X 币怎么拿

  • 入门赛：AK 得 20 X 币，各题首 A 额外 10 X 币。
  • 周赛／月赛：AK 得 50 X 币，各题首 A 分别 10、15、20、30 X 币。
  • 周赛／月赛前五名：30、25、20、15、10 X 币（AK 与排名奖励互斥）。
  • 周赛／月赛只要得分：额外 5 X 币。
  • 成功举办成员赛：100 X 币。
  • 群内分享优质题解：少量 X 币奖励。

X 币什么时候扣

  • 周训练未达标（不足 200 分或未提交）：每次扣 10 X 币。
  • 比赛中作弊：扣除全部 X 币，并取消一段时间参赛资格。
  • 群内恶意吵架、刷屏、发无关广告：视情节扣币或禁言。
  • 兑换道具：补签卡 15、延长卡 20、申诉券 25、免扣卡 40 X 币。
  • 自愿退队：个人 X 币全部清空，重新入队从零开始。
